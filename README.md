# No More Marble Racing

A strategic Tower Defense game built with the Godot Engine. Stop the marbles from racing to the finish line by constructing powerful towers and using tactical upgrades!

## 🎮 Game Overview

In **No More Marble Racing**, waves of marbles are trying to complete the track. Your goal is to stop them at all costs. You start with limited money and lives—spend wisely to survive all 4 rounds on each map!

### 🗺️ Maps
- **Green Fields**: A lush, beginner-friendly path.
- **Desert**: A winding path through the arid dunes.
- **Nostalgia**: A retro-themed challenge for experienced defenders.

## 🏰 Towers

Choose your defense strategy carefully:

*   **🏹 Blue Arrow Tower**: Reliable, single-target damage. Good for picking off weak enemies.
*   **🔴 Red Bullet Tower**: High rate of fire to whittle down health quickly.
*   **💣 Purple Bomb Tower**: Launches explosive projectiles that deal Area of Effect (AoE) damage. Perfect for clustered groups.
*   **❄️ Orange Slow Tower**: Slows down marbles within range, giving your other towers more time to attack.

## 🎱 The Marbles (Enemies)

Beware of different marble types!
*   **Basic Marbles**: Standard speed and health.
*   **Splitting Marbles**: Break apart into smaller marbles when destroyed (watch out for Marble D!).
*   **Support Marbles**: Marble E boosts the speed of other marbles around it. Take it out first!

## 🕹️ How to Play

1.  **Select a Level** from the Main Menu.
2.  **Click on a Tower** in the bottom menu to select it.
3.  **Click on the Map** to place the tower (ensure you have enough Money 💰).
4.  **Click on an existing Tower** to see its range or Upgrade it for better stats.
5.  **Press "Next Round"** (Play button) to start the wave.
6.  Survive **4 Rounds** to win!

## 🛠️ Installation & Running

This project is built with **Godot 4.x**.

1.  Clone this repository.
2.  Open Godot Engine.
3.  Click **Import** and select the `project.godot` file in the root directory.
4.  Press **F5** or click the **Run** button to start the game.
